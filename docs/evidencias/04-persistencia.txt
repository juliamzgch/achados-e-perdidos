Legenda: os dois objetos e fotos permanecem no banco/volume após recriação dos serviços com Nginx.

Comandos de leitura para reproduzir a verificação:

```sh
curl -fsS http://localhost:8080/estatisticas
curl -fsS http://localhost:8080/itens
docker compose exec web ls -l /app/uploads
```

Para conferir uma foto específica, copie seu nome de `GET /itens`:

```sh
PHOTO_NAME="nome-da-foto-retornado-pela-api.png"
curl -sS -o /dev/null -w "%{http_code}; %{size_download} bytes\n" \
  "http://localhost:8080/fotos/$PHOTO_NAME"
```
