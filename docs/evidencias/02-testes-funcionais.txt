Legenda: testes funcionais da versão final, com Nginx como único serviço que publica uma porta no host.

Comandos para reproduzir os testes GET:

```sh
curl -fsS http://localhost:8080/health
curl -fsS http://localhost:8080/itens
curl -fsS "http://localhost:8080/itens?local=biblio"
curl -fsS http://localhost:8080/estatisticas
```

Comandos para conferir estado, usuário e logs:

```sh
docker compose ps
docker compose exec web whoami
docker compose logs --tail 20 nginx web
```

Para repetir os cadastros multipart, troque o caminho pelo de uma imagem local
existente. Cada POST cria um novo registro; as respostas abaixo são os resultados
capturados no teste original, não saídas desta repetição.

```sh
curl -fS \
  -F "descricao=Oculos de teste" \
  -F "local=Bloco B" \
  -F "foto=@/caminho/real/oculos.png" \
  http://localhost:8080/itens

curl -fS \
  -F "descricao=Chave de teste" \
  -F "local=Laboratorio 2" \
  -F "foto=@/caminho/real/chave.png" \
  http://localhost:8080/itens
```

Para conferir uma foto, use o nome devolvido pelo POST ou listado em `GET /itens`:

```sh
PHOTO_NAME="nome-da-foto-retornado-pela-api.png"
curl -sS -o /dev/null -w "%{http_code}; %{size_download} bytes\n" \
  "http://localhost:8080/fotos/$PHOTO_NAME"
```
